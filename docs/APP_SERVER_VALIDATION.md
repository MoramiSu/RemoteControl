# Codex App Server 验证记录

日期：2026-09-17。范围：本机独立 App Server 原型，不改动一期飞书桥接。

## 结论

部分通过，暂不作为二期正式执行后端。协议、当前账号的历史任务列表读取、临时会话创建及中断终态已实测；模型回复被上游请求超时阻塞。上下文接续、原生问题答复、权限审批和桌面接续尚未完成实测。

## 环境与方法

- 本机 CLI：`0.154.0-alpha.6.2`，桌面附带版本。
- 通过 `codex app-server generate-json-schema` 生成本机协议，不能直接套用网上示例。
- 传输：独立子进程 stdio，无监听公网端口。
- 隔离沙箱账号无用户登录；实际 Windows 用户下 `account/read` 返回 ChatGPT 账号类型。该结果只代表存在登录状态，不证明模型请求成功。
- 执行测试使用 `ephemeral: true`、只读沙箱、无工具提示词；未知审批请求拒绝。未向既有任务投递，未发送飞书消息。

## 验证结果

| 检查 | 结果 | 证据或限制 |
| --- | --- | --- |
| 初始化握手 | 通过 | initialize 返回版本、平台等信息 |
| 账号读取 | 通过 | account.type 为 chatgpt，不输出账号详情或密钥 |
| 历史任务列表 | 通过 | limit=5 返回 5 项；不是任务总数 |
| 运行实例归属 | 独立实例 | 新进程 thread/loaded/list 为空，不能据历史列表宣称接管桌面 |
| 临时任务创建 | 通过 | thread/start 返回 ephemeral 会话，模型为配置默认值 |
| 发送普通消息 | 部分通过 | turn/start 接受请求；未收到最终文本 |
| 模型输出 | 未通过 | 日志出现 sampling_error=request timed out，持续重连 |
| 中断 | 通过 | turn/interrupt 后收到 turn/completed，status=interrupted |
| 上下文接续 | 未验证 | 首轮没有完成，未执行后续记忆检查 |
| 原生问答/审批 | 仅确认协议定义 | 本机存在请求与响应 schema，未形成真实端到端交互 |
| 重启恢复、桌面接续 | 未验证 | 临时会话测试不证明持久化和桌面共享能力 |

第一轮回复等待 60 秒，第二轮等待 45 秒；诊断轮延长到 100 秒。超时后请求中断，不自动重发到既有任务。单独的中断测试只证明活动轮次可以进入中断终态，不证明外部工具子进程均已停止，也不代表可以中断桌面已有任务。

## 后续建议

1. 优先定位独立进程的上游连接：网络/代理环境、登录有效性与桌面宿主差异。当前错误不足以断言需要重新登录或缺少某项宿主能力。
2. 连接恢复后，以相同测试夹具完成两轮文本与上下文验证，再测试真实问答及审批的接受、拒绝、过期。
3. 使用持久化专用测试任务验证重启恢复和桌面可见性，禁止并发恢复正在执行的生产任务。
4. 上述检查通过前保持一期 DesktopAdapter 不变。协议文件应按实际二进制版本生成并锁定。

参考：[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。文档列出的能力与本机已经通过的实测项应分别记录；官方仍标注实验性限制。
